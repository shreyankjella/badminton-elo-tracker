# Badminton Elo Tracker

Record badminton results, update player ratings, and check head-to-head wins.

## Run

Open this folder in VS Code and run:

```bash
python main.py
```

No extra packages are required.

## Try it

Record a match, view rankings, then look up the same two players head-to-head.

## How it works

Elo starts each player at 1000 and uses K=32. Results are kept in memory until the program closes.
